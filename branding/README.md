# Relic – Branding

Verbindliches Design und Logo von Relic, für App und Website.
Website: https://relicjournalapp.com

- **[DESIGN.md](DESIGN.md)** – Farben, Schriften, Abstände, Bausteine, Logo-Regeln.
  Die einzige verbindliche Quelle für das Aussehen.
- Logo- und Symbol-Dateien (wann welche Variante passt: DESIGN.md, Abschnitt 5):

| Datei | Wofür |
|---|---|
| `relic-icon.svg` | Vektor, quadratisch – Website, Druck, beliebig skalierbar |
| `relic-icon-round.svg` | Vektor, rund zugeschnitten |
| `relic-icon-512.png` | Play-Store-Symbol (512 × 512) |
| `relic-icon-1024.png` | Medien, Präsentationen |
| `relic-icon-round-1024.png` | Rund, z. B. Profilbilder |

Das Symbol: großes, angeschnittenes „R“ mit gefülltem Punkt,
Tinte (`#24221E`) auf Weiß (`#FFFFFF`). Die Quelle in der App ist
`app/src/main/res/drawable/ic_launcher_foreground.xml` (gleicher Pfad wie in den SVG-Dateien).

Die Buchstabenform stammt aus der Schrift Fraunces (SIL Open Font License 1.1, siehe
`app/src/main/assets/licenses/`). Die Lizenz erlaubt, Buchstaben daraus für ein Logo zu verwenden.
