# Relic – Logo

Das App-Symbol von Relic: ein großes, angeschnittenes „R“ mit dem Punkt aus dem Zeitstrahl,
Tinte (`#24221E`) auf Papier (`#EFE9DF`).

| Datei | Wofür |
|---|---|
| `relic-icon.svg` | Vektor, quadratisch – Website, Druck, beliebig skalierbar |
| `relic-icon-round.svg` | Vektor, rund zugeschnitten |
| `relic-icon-512.png` | Play-Store-Symbol (512 × 512) |
| `relic-icon-1024.png` | Medien, Präsentationen |
| `relic-icon-round-1024.png` | Rund, z. B. Profilbilder |

Die Quelle in der App ist `app/src/main/res/drawable/ic_launcher_foreground.xml`
(gleicher Pfad wie in den SVG-Dateien).

Die Buchstabenform stammt aus der Schrift Fraunces (SIL Open Font License 1.1, siehe
`app/src/main/assets/licenses/`). Die Lizenz erlaubt, Buchstaben daraus für ein Logo zu verwenden.
